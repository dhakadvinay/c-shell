RISC-V Assembly Calculator

What it does: This project contains low-level functions written in RISC-V assembly language to solve math problems like the Collatz conjecture, palindrome checking, and bit counting.

Why I built it: I built this to understand how software talks to hardware. Writing in high-level languages like Python hides how memory and CPU registers actually work. This forced me to manage memory manually.

What I would change: Writing in raw assembly is very slow. In the future, I would write the main program in C and only write the most performance-critical math functions in inline assembly.

Technology tradeoffs: The massive tradeoff here is speed vs developer time. Assembly code runs incredibly fast because it is closest to machine code. However, it takes ten times longer to write a simple loop in assembly than it does in JavaScript.
